# Scope

This submission indexes all eleven supplied source files: nine PDFs, the 2023-24 Union Budget CSV, and the historical Union Statement 20 XLS. PDF extraction is page-level so citations retain the original filename and page number. The CSV is indexed row-by-row, preserving its aggregate and scheme rows. The XLS is read without assuming a header row; that preserves its title and narrative cells as well as the later table, which is important because two development answers occur in prose above the spreadsheet headers.

The system is intentionally a lightweight retrieval baseline, not a general-purpose financial reasoning model. It uses TF-IDF word and bigram search over extracted chunks, with a small year-aware reranking boost. This is especially useful for the nearly identical Delhi budget PDFs, where the same scheme changes values across years. It also includes a few query-expansion hints for the Hindi evaluation questions. The supplied JSON has mojibake for Hindi strings, so the query normalizer attempts a Latin-1-to-UTF-8 repair first; it then searches the English parallel line in the bilingual documents. This is more reliable than relying on Hindi PDF extraction, which largely exposes legacy-font glyph codes.

I did not OCR scanned/garbled pages, reconstruct table geometry, or use an LLM to synthesize answers. Consequently, table columns are understood through surrounding headers and manually verified for the submitted evaluation answers. The output declines questions outside the corpus: Delhi years 2012-13, 2018-19, and 2019-20; Kerala; and Delhi's overall education budget. It also declines Odisha's Mahila Samriddhi Yojana because no such allocation was found in the supplied Odisha document. These are deliberate abstentions rather than guesses. Page numbers for PDFs are the source PDF page indices; non-PDF citations use their row/location metadata.
